# GhostWriter AI | Content Engine

![GhostWriter Preview](https://img.shields.io/badge/Ayanlogix-AI_Content-yellow?style=for-the-badge)
![Private](https://img.shields.io/badge/Status-Private-red?style=for-the-badge)

**GhostWriter AI** is an intelligent content generation engine powered by Gemini AI. It allows users to "manifest" their ideas into professional, witty, or inspiring social media content across multiple platforms like LinkedIn, Twitter, and Instagram.

## 🚀 Key Features
- **Multi-Platform Support**: Tailor content specifically for LinkedIn posts, Twitter threads, or Instagram captions.
- **Tone Orchestration**: Switch between Professional, Witty, Inspiring, and Casual tones with a single click.
- **AI-Powered Manifestation**: Uses high-performance LLMs (Gemini AI) to transform brief ideas into viral content.
- **Content History**: Keep track of your "Recent Works" and previous generations in a persistent sidebar.
- **Minimalist Aura UI**: A focused, distraction-free writing environment with subtle animated background auras.

## 🛠️ Technical Stack
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3
- **AI Integration**: Gemini AI (via Google Generative AI API)
- **Design**: Space Grotesk & Outfit (Typography), Aura-Glow styling
- **Architecture**: Modular component-based frontend for rapid content streaming
